# Corteva Agriscience – Vendor Scorecard Dashboard

**Role:** Power BI Developer (Contract via Momento USA) · Remote · Oct 2023 – Dec 2025

## Business Problem
Corteva's supply chain team needed a standardized way to evaluate vendor performance across multiple KPIs. Reporting was fragmented and leadership lacked a single source of truth for vendor accountability decisions.

## What Was Built
An executive-level vendor performance scorecard dashboard built end-to-end in Power BI — from requirements intake through deployment and stakeholder training.

**Highlights:**
- Designed the semantic model using star schema architecture for scalable, reliable reporting
- Implemented Row-Level Security (RLS) so each business unit sees only their relevant vendor data
- Validated report accuracy using SQL checks against Snowflake source data prior to distribution
- Conducted stakeholder interviews and usability testing to align visuals with business objectives
- Built a Power Automate workflow to ingest Excel attachments into SharePoint, reducing manual data prep by 30%
- Delivered training and documentation for ongoing self-service use

## Tools
Power BI Desktop · DAX · Power Query (M) · SQL · Snowflake · Power BI Service (RLS, scheduled refresh, app publishing)
