# Power BI Projects – Sample Dashboards

This folder contains sample Power BI work demonstrating dashboard design, DAX development, and data storytelling across different business scenarios.

## Sales Performance Analysis Dashboard

**Business Problem:**
Business units were relying on static Excel reports with no filtering, no drill-through, and no consistent KPI definitions across regions.

**What Was Built:**
An end-to-end sales performance dashboard with dynamic filtering, trend analysis, and executive-level KPI tracking — migrated from Excel to Power BI for real-time access and consistency.

**Highlights:**
- Consolidated regional reports into a single dashboard, reducing monthly reporting effort by ~4 hours per cycle
- Developed complex DAX measures using iterators (SUMX, AVERAGEX) to model real-world business scenarios
- Used SQL window functions (LAG, ROW_NUMBER, RANK) and CTEs to calculate YoY growth, trend analysis, and rolling metrics
- Applied Power BI best practices: bookmarks, drill-through, field parameters, and performance tuning
